=====================================
SERVICE MARKETPLACE - XAMPP Project
=====================================

HOW TO RUN:
1. Copy this folder to: C:\xampp\htdocs\service-marketplace\
2. Start Apache in XAMPP Control Panel
3. Open browser: http://localhost/service-marketplace/

FEATURES:
- Public Site: Home, Categories, Provider Profiles, Request Quote, Login
- User Dashboard: My Requests, Request Detail, Leave Review

PAGES:
- index.html     → Public Site (Home)
- dashboard.html → User Dashboard (My Requests)

FILES STRUCTURE:
├── index.html
├── dashboard.html
├── css/
│   └── dashboard-styles.css
├── js/
│   └── app.js  (All functionality)
└── README.txt

DATA:
- Requests are stored in localStorage (browser)
- Demo data is loaded automatically

NEED HELP?
- Open js/app.js to modify functionality
- Open css/dashboard-styles.css to change styling
- DataStore object contains all mock data
